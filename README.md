# Evaluación práctica Spring Boot — Biblioteca universitaria

Versión: Java 17.

Ejecución:

```bash
chmod +x gradlew
./gradlew bootRun
```

Swagger UI después de completar R1:

```text
http://localhost:8075/api/swagger-ui.html
```

La base H2 se crea automáticamente desde `schema.sql` y `data.sql`.
